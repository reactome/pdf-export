# pdf-export

Reactome's pathway PDFs from the graph: the release's book (`TheReactomeBook`) and
the website's PDF of one pathway or reaction, from one implementation, under loose
open-source licences, with diagrams in the website's pathway browser's look. It is
to replace [`reactome/event-pdf`](https://github.com/reactome/event-pdf).

The work is specified before it is built: see [`specs/`](specs/) and
[`CLAUDE.md`](CLAUDE.md). The principles are in
[`.specify/memory/constitution.md`](.specify/memory/constitution.md).
